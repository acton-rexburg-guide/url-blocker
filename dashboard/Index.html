2. Who these settings apply to

Group settings override OU settings. Sub-OUs inherit from their parent until you save settings on them.

3. Rules

A domain covers its subdomains (google.com includes docs.google.com). Add a path to match only part of a site (youtube.com/shorts).

4. Schedules change the rules on certain days and times

While a schedule is on, its sites are added to the lists above and it can switch the mode. If several are on, the one lowest in this list decides the mode. An end time earlier than the start runs past midnight.
